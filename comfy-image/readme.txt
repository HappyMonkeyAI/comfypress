A WordPress plugin that integrates ComfyUI with Gutenberg to generate images from text prompts. This workspace contains a scaffold for the plugin, admin settings, and example workflow templates.

Installation
1. Copy the `comfy-image` folder into `wp-content/plugins/`.
2. Activate the plugin via the WordPress admin.
3. Visit Settings → Comfy Image to configure the ComfyUI Base URL and options.

Notes
- This is an initial scaffold. Further development will add AJAX/REST endpoints and a Gutenberg block.
