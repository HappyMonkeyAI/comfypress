ComfyPress — ComfyUI WordPress Plugin (workspace)

This workspace contains assets for the Comfy Image WordPress plugin (working name `comfy-image`).

Overview
- Plugin goal: Allow Gutenberg users to generate images using a remote ComfyUI instance via slash command `/comfy` or a Gutenberg block.
- Project files: `project.json`, `PLAN.md`, and example integrations under `image-image-gen/` and `LLM_Auto_Redirect_v1.2.0/`.

See `PLAN.md` and `project.json` for the current project plan and machine-readable manifest.
